# 成绩打怪 · 进阶版

高考分数对照目标分、生成战报与补弱建议。成绩只存在浏览器本地，不会上传。

**在线使用：** [https://wangdwn.github.io/gaokao.github.io/](https://wangdwn.github.io/gaokao.github.io/)

## 功能

- 录入语文、数学、英语、物理、化学、生物成绩（默认理科目标分，可在 `index.html` 配置区修改）
- 进度条、总分对照、弱科 Top 3 建议
- 深色模式；刷新后自动恢复上次录入
- 页内「官方入口」链到教育部 2026 高考专题、阳光高考、国家智慧教育平台

## 本地打开

用浏览器直接打开 `index.html` 即可，无需构建。
